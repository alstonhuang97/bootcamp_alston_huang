# Homework - Stage 02

This project is a homework assignment for Stage 02 of the bootcamp, demonstrating a standard setup workflow: an isolated virtual environment with dependencies, secrets management via a `.env` file (loaded and validated through `src/config.py`), and a Jupyter notebook (`notebooks/00_project_setup.ipynb`) that verifies the environment is configured correctly and runs a basic NumPy check.
